# PoopSense · 便知

**面向家庭排便记录场景的智能硬件项目。此仓库提供可运行的公开演示、展示组件和设备接口示例。**

公开版演示：提交合成观测 → 形状与颜色卡通 → 示例报告 → 保存与回看。

展示组件选自项目截至 2026-10-03 的本地版本。为了保留核心算法与私有数据，本仓库为这些组件配套独立的演示入口和本地接口适配层，并非线上系统的完整副本。

## 快速运行

需要 Python 3.10+、Node.js 22.12+（本次验证使用 Python 3.12、Node.js 24）。无需设备、模型密钥或 Python 第三方依赖。

```sh
git clone https://github.com/poopsense/poopsense.git
cd poopsense
python backend/demo_server.py
```

另开终端，在仓库目录执行：

```sh
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```

打开 **http://127.0.0.1:5173**，选择形状与颜色，点击“提交并查看结果”。刷新页面或重启本地服务后，可在历史记录中回看。Windows 上如 `python` 不可用，可用已安装的 `py -3` 替代。

后端固定监听本机回环地址，默认 8000 端口。数据保存到本机 `backend/.demo/sessions.sqlite3`，不上传云端。端口被占用时应先处理占用，不要修改代理指向线上服务。

## 公开内容与边界

| 内容 | 本仓库状态 |
|---|---|
| 形状/颜色可视化、报告正文展示 | 复用最新本地组件，附对应测试 |
| 上传、重复请求处理、查询、历史记录 | 独立本地演示实现，SQLite 保存合成数据 |
| 报告 | **固定示例**，不是本次模型生成；页面明确显示来源 |
| 设备上传客户端 | 基于现有客户端提取，固定访问本机，保留原始请求归档和拒绝重定向行为 |
| 传感分类、标定、核心 Agent、模型路由实现 | 不包含 |
| 固件、真实样本、用户数据、私有配置 | 不包含 |
| MCP、手表、桌宠接入 | 项目正在探索，不作为本公开演示能力 |

卡通按输入标签展示，不从原始传感数据推理；模板相似度不等于分类置信度。公开演示不证明真实硬件测量、健康判断准确性或完整自主 Agent 执行能力。

## 验证

```sh
python -m unittest discover -s backend -p "test_*.py" -v
cd frontend
npm test
npm run build
```

`npm run build` 生成前端静态文件，并不把本机演示服务变成生产后端。此版本不提供公网身份认证与家庭数据隔离，不应接收真实私人数据或作为公网服务部署。
