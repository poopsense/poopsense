# 原型状态

更新：2026-10-03。此页区分项目原型和本仓库的本地示例，方便评估与复现。

## 已有的产品流程

设备记录上传后，Web界面按观测展示形状与颜色，并请求模型生成结构化报告。报告包含观察、建议及待补充问题；生成结果保存后可以回看，重复读取复用已有结果。服务端保留事实校验、生成状态、重试和版本记录。

2026-09-29的内部验收记录包含两条已有设备记录的真实DeepSeek报告生成、保存及重复请求复用。这次验收没有新增硬件测量，也不表示健康建议已获得医学有效性验证。原型入口见 [poopsense.org](https://poopsense.org)。

## 模块与当前接通范围

| 模块 | 项目实现与限制 | 本仓库 |
|---|---|---|
| 设备记录与结果展示 | 设备上传、样本可视化、报告与回看 | 提供客户端、展示组件和合成接口 |
| 模型报告 | 真实模型生成，结构与观测事实校验 | 使用固定报告示例 |
| 多模型接入 | 通用层支持配置及任务路由；当前演示报告路径限定DeepSeek | 不包含模型实现 |
| 任务状态 | 已有任务、步骤、转交及暂停/恢复记录；技能选择主要由规则完成 | 不包含任务引擎 |
| 行动跟进 | 已有存储和接口；当前手动采样记录不进入该流程 | 不包含 |
| 家庭操作确认 | 已有确认/取消状态；确认后的对话解释下一步，尚未自动执行家庭变更 | 不包含 |
| 补充信息 | 报告已有问题提示，当前演示尚未支持填写后重新分析 | 不包含 |
| MCP与跨设备反馈 | 正在探索接入，尚无本页可引用的完整验收 | 不包含 |

任务状态记录不等于模型自主规划或已执行外部动作。对外演示应展示实际触发、调用和结果；尚未接通的流程继续按开发中说明。

## 数据与复现

本仓库只接收合成示例，不能用其固定输出验证原型模型或传感算法。真实样本、访问凭据及内部验收记录不随源码发布。

硬件测试模式、样本性质和模型报告模式需要分别标记。现有演示报告仍使用模拟情境措辞，因此评估实物演示时，应结合同条记录的采集说明核对，不能仅凭报告字样判断样本来源。
